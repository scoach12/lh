# Liebe & Heilung - Therapeutische Website

Eine professionelle Website für Dr. med. Sabrina Kising, Fachärztin für Gynäkologie und Geburtshilfe mit Spezialisierung auf Trauma-Therapie, Paar- und Sexualtherapie.

## 🌟 Aktueller Stand

### Kürzlich hinzugefügte Features
- ✅ **Optimiertes Logo**: 80px großes "Liebe-Heilung" Logo ohne Text im Header für maximale Sichtbarkeit
- ✅ **Eye-Catcher Zoom-Animationen**: Professionelle fadeInScale-Effekte auf allen Therapie-Seiten
- ✅ **Meetergo Terminbuchung**: Professionelle Online-Terminvereinbarung (24 Buttons integriert)
- ✅ **Verlinkte Blog-Artikel**: Echte Blog-Artikel auf der Startseite verlinkt
- ✅ **Gestylte Kontaktformulare**: Professionelle Modal-Integration mit Orange-Emerald Design
- ✅ **Vollständige FAQ-Sektionen** auf allen drei Therapie-Seiten
- ✅ **Unified Orange-Emerald Design** durchgängig implementiert

### Hauptfunktionen
- **Responsive Design** mit Orange-Emerald Farbschema
- **3 Therapie-Bereiche**: Trauma-, Paar- und Sexualtherapie
- **Professioneller Blog** mit 4 Artikeln (3 Featured auf Homepage)
- **Verlinkte Blog-Artikel** auf der Startseite mit echten Links
